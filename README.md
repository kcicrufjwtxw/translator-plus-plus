## 🤖 Overview

Translator++ is a translation management platform for visual novels and RPG Maker games, providing a spreadsheet editor, machine translation, and export tools.

Whether you're a newcomer or a veteran, Translator++ provides the tools you need to get the most out of your ai tools experience. Designed for Windows and macOS, it delivers a seamless, high-performance workflow.

## ✨ Key Features

| Feature | Description |
|---|---|
| **Script Importer** | Imports scripts from RPG Maker, Ren'Py, and KiriKiri engines |
| **MT Integration** | One-click machine translation via DeepL, Google, or ChatGPT |
| **Glossary Manager** | Enforces consistent term translation across the entire project |
| **Patch Exporter** | Exports finished translations as installable game patches |
